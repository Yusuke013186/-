# タスク②-2　個別症例推移を論文化するかの検討メモ

**位置づけ**：本メモは上野先生との相談材料である。論文化の是非についてClaude Code側で結論は出していない。以下は賛成／反対の論点整理までにとどめる。

対象データ：18か月MMSEデータを有する29例（改善訴えあり n=9／改善訴えなし n=20）。

---

## 1. 図から読み取れることの要約

集団平均では2群に差がない（結果5：18か月時点 Welch t 検定 p=0.804、Mann-Whitney p=0.617、ベースラインMMSE調整後 p=0.879）。しかし個別軌跡を重ねると、両群は「同じように推移した29例」ではない。

| 指標 | 改善訴えあり (n=9) | 改善訴えなし (n=20) |
|---|---|---|
| ベースラインMMSE | 22.89 ± 1.76 | 24.25 ± 2.07 |
| Δ MMSE（18か月） | +0.22 ± 4.76 | −0.75 ± 2.83 |
| Δ MMSE の範囲 | −8 〜 +5 | −9 〜 +4 |
| 個人内変動幅（4時点の最大−最小）の平均 | **4.67点** | **3.05点** |
| ピーク上昇幅（最高値−ベースライン）の平均 | **2.67点** | **1.15点** |
| 18か月で改善／不変／悪化 | 6／0／3例 | 7／4／9例 |

読み取れるパターンは3点である。

1. **訴えあり群のほうが軌跡のばらつきが大きい。** 個人内変動幅の平均で 4.67 対 3.05、Δ18MのSDで 4.76 対 2.83。訴えあり群には +5点の症例と −8点の症例が同居している。差は平均の水準ではなく、分散の側に現れている。
2. **訴えあり群は6か月時点で一過性に上昇する。** 群平均のΔMMSEは6か月で +1.67点（なし群は −0.10点）で、これが12か月には +0.22点まで戻る。この一過性の山が「効いている」という実感の時期と対応している可能性はあるが、本データでは訴えの記録時期を特定できていない。
3. **訴えあり群は「不変」がゼロである。** 18か月時点でベースラインと同点の症例は、なし群には4例あるが、あり群には0例。全例が動いている。

**重要な留保**：訴えあり群のベースラインMMSEは有意ではないもののなし群より低く（22.89 対 24.25）、平均への回帰の影響を否定できない。実際、29例全体でベースラインMMSEとΔ18Mは r = −0.50 (p=0.006) と相関するが、Δがベースラインを含んで計算される以上、この相関には数学的な平均への回帰が含まれる。上記1〜3を「訴えありという臨床像の特徴」として読むことは、現時点ではできない。

---

## 2. 論文の独立セクション／補足図にする価値：賛成の論点

- **陰性所見に説明を添えられる。** 「差がない」だけの結果は査読で弱い。個別軌跡を示せば、平均が重なる理由が「両群とも動かなかった」からではなく「両群とも大きく動いたが方向が揃わなかった」からだと示せる。これは結果5の解釈を一段深くする。
- **先行研究の枠組みに乗る。** Cano ら（J Prev Alzheimers Dis 2022）は、全般的印象アンカーとMMSEが短期的に対応しないことを示している。本研究の図はその追認であり、「検出力不足による陰性」ではなく「既知の現象の再現」として提示できる。査読者への回答としても使える。
- **抗アミロイド抗体の実臨床データとして情報量がある。** レカネマブ投与例の個別MMSE軌跡を18か月まで追った実臨床データは、それ自体が報告価値を持つ。群分けの当否と独立に、補足図（Supplementary Figure）としては受け入れられやすい。
- **分散に着目するという仮説を生成できる。** 「主観的な改善の訴えは、認知機能の水準ではなく変動しやすさと関連するのではないか」という次の研究の問いを立てられる。探索的所見として明示すれば、過剰な主張にはならない。

## 3. 反対の論点

- **n=9 では分散の議論が成り立たない。** 分散の群間比較（Levene検定等）は n=9 では極めて不安定で、個人内変動幅 4.67 対 3.05 という差も1〜2例の外れ値で消えうる。査読で最初に突かれる点である。
- **事後的な指標選択である。** 「個人内変動幅」「ピーク上昇幅」は図を見てから定義した指標であり、事前登録された仮説ではない。多重性の管理ができておらず、論文の主題に据えると HARKing（結果を見てから仮説を立てること）の批判を受ける。
- **平均への回帰と交絡している。** 上記のとおり、ベースラインの差（22.89 対 24.25）と平均への回帰で説明が付いてしまう可能性を、本データでは排除できない。
- **群分け変数そのものの妥当性が弱い。** 「症状改善の訴え」は診療録記載に基づく二値変数であり、記載バイアスを受ける（詳細は参考3スライドおよび `文献調査_意欲低下定義.md`）。曝露変数の測定に問題がある以上、そこから派生する二次的な所見の説得力は上限が決まる。
- **主題が散る。** 論文の主張が「主観と客観は乖離する」であるなら、分散の話は独立セクションにするほど中心的ではない。補足図に留めるほうが構成は締まる。

## 4. 落としどころの案（判断は上野先生に委ねる）

| 案 | 内容 | 向いている状況 |
|---|---|---|
| A | **補足図（Supplementary）に留める。** 本文では結果5のみを扱い、個別軌跡は補足として「平均の重なりが均一な推移を意味しないこと」を示すだけにする。分散の数値には踏み込まない。 | 論文の主題を「主観と客観の乖離」に絞りたい場合。**最も安全** |
| B | **本文の図として入れるが、記述に留める。** 個人内変動幅などの数値は示すが、検定はせず「探索的観察」と明記する。考察で次研究の仮説として言及する。 | 実臨床データとしての情報量を売りにしたい場合 |
| C | **独立セクションにする。** 分散に着目した解析を主題の一つに格上げする。 | 追加症例やベースライン揃えなど、指摘に耐える補強ができる場合。**現時点では推奨しない** |

Claude Code としての所見を述べるなら、現在のデータでは A または B が妥当と考える。ただし採否の決定は行っていない。
