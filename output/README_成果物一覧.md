## 3. 検証済みの数値

### 群定義の再現性（フェーズ0）
指示書の定義（`レカネマブ投与後に何らかの症状改善の訴えあり` ＝ `あり`／`記載なし` かつ 18か月MMSEデータあり）で **n=9 / n=20 を再現**した。

- 訴えあり (n=9)：L1, L2, L3, L4, L6, L8, L15, L32, L45
- 訴えなし (n=20)：L7, L9, L11, L12, L13, L16, L17, L19, L21, L22, L23, L24, L25, L26, L27, L28, L30, L31, L33, L34
- 全体(N=66)：あり 17例／記載なし 49例

### 結果5スライドとの整合性
既存スライドの数値をすべて独立に再現した。

| 項目 | スライド記載値 | 再計算値 |
|---|---|---|
| 訴えあり群 平均MMSE（0/6/12/18か月） | 22.89 / 24.56 / 23.11 / 23.11 | 一致 |
| 訴えなし群 平均MMSE（0/6/12/18か月） | 24.25 / 24.15 / 23.84 / 23.50 | 一致 |
| Welch t 検定 p | 0.804 | 0.804 |
| Mann-Whitney p | 0.617 | 0.617 |
| ベースラインMMSE調整後 p | 0.879 | 0.879 |

### 結果1（患者背景）との整合性
精神症状シートの集計が結果1の表と一致：易怒性 15/66 (22.7%)、意欲低下 22/66 (33.3%)、両方なし 31/66 (47.0%)。

### タスク③の統計結果
MMSE下位項目11項目・CDR6領域について、18か月時点のベースラインからの変化量をMann-Whitney検定で比較し、Benjamini-Hochberg法でFDR補正。

- **MMSE 11項目：補正前 p<0.05 は 0/11、FDR補正後 q<0.05 も 0/11**（最小 p=0.157、最小 q=0.778）
- **CDR 6領域：補正前 p<0.05 は 0/6、補正後 q<0.05 も 0/6**（最小 p=0.598）
- 参考：CDR-SB のΔ18M は 訴えあり +1.75±2.71 対 訴えなし +1.39±0.98、p=0.736

補正前の段階ですでに有意な項目がないため、「補正して消えた」のではなく「もともと差がない」。全図・全メモに探索的解析である旨を明記した。

## 5. 品質管理の実施内容

1. **群定義の再現性**：フェーズ0で n=9/n=20 を確認済み（上記）。
2. **多重比較補正**：タスク③はすべて補正前 p 値と FDR補正後 q 値を併記し、探索的解析である旨を図キャプション・スピーカーノート・メモに明記。
3. **PowerPoint QA**：LibreOffice で PDF 化 → PNG 化して全8枚を目視確認。初回QAで検出した「タイトルの2行折り返しによる罫線・サブタイトルとの衝突」「参考3の本文が下端からあふれる」「キャプションの折り返し」を修正済み。最終版は溢れ・重なりなし（`output/qa/`）。
4. **結果1・結果5の非改変検証**：更新版pptxの `slide1.xml` / `slide2.xml` を元ファイルとXML比較し、内容が同一であることを確認（差分はXML宣言・空白のみ）。
5. **未確定事項の一覧化**：`上野先生・堀内先生への確認事項リスト.md` に集約。削除等の不可逆な操作は一切実行していない。
