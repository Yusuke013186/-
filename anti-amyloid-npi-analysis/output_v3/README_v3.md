# output_v3 — 上昇群と非上昇群で差を示す項目の網羅的探索

NPIアパシースコアが上昇した群（5例）と上昇しなかった群（9例）のあいだで
差を示す項目が存在するかを、取りこぼしなく探した記録である。

## 結論

**2,502項目を検定したが、多重性を補正して有意となった項目はなかった。**

| 指標 | 値 |
|---|---|
| 列挙した候補 | 6,974（重複を除くと 2,504） |
| p値を計算できた候補 | 2,502 |
| うち p<0.05 に到達しうる候補 | 2,232 |
| 実際に p<0.05 だった候補 | 3 |
| BH-FDR で q<0.05 | 0 |
| min-p 並べ替え（Westfall-Young）による FWER 補正p | **0.925** |
| 実効的な独立検定数（min-pから逆算） | 59.6 |
| 実効数に基づく p<0.05 の期待件数 | 3.0（実測 3 と一致） |
| エネルギー距離検定（プロファイル全体） | p=0.64〜0.82 |

候補どうしが強く相関しているため、実効的な独立検定数は約60である。
偶然だけで p<0.05 となる件数の期待値は約3件であり、実測の3件と一致する。
すなわち観測結果は「群間に差がない」という帰無仮説と完全に整合する。

これは「差がない」「関連しない」ことの証明ではない。
この例数とこのデータでは差を検出できなかった、という意味である。

## 探索した範囲

- 初回値・追跡時値・変化量・年換算変化量・月あたり変化量・相対変化率
- MMSE 11下位項目の**全部分集合**（2^11−1＝2047通り）の和
- CDR 6領域の**全部分集合**（2^6−1＝63通り）の和
- 下位項目どうしの差（解離の指標）
- 固定時点（6・12・18・24か月）での値と変化量
- 連続量を**あらゆる切点**で2値化した比較（Fisher 正確確率検定）
- 初回値で調整した変化量（回帰残差・並べ替えANCOVA）
- 悪化／改善／不変の別、悪化した下位項目の数、変化方向の組み合わせ
- 患者背景（年齢・性別）、観察期間、記録上の条件
- 群分けの切り方を変えた9通りの感度解析

すなわち「どの下位項目をどう足し合わせるか」という形の加算型指標については、
原理的に取りこぼしがない。

## 解析の原則

- 有意になった項目だけを選び出して報告していない。列挙した候補はすべて収載している。
- 欠測を0点として扱っていない。値の訂正・補完・除外も行っていない。
- 群分けの定義に直結する項目は同義反復として主探索族から除外している。
- この解析は既存データを確認したのちに行ったものであり、
  研究開始前に規定した解析ではない。
