福井県済生会病院 脳神経内科の後方視的観察研究に対する解析コード。
2026年9月18日の議事録の方針（NPI第7項目＝アパシー・無関心、第9項目＝易怒性の「有無」を

## 解析の要点

### 時点の突合
NPIシートの時点ラベルは原資料と一致しない（「18か月」と統一された記載の原資料上の時点は
12〜30か月に分布する）。さらに NPI フォローアップの実評価日はほぼ全例が2026年8〜9月に集中し、
MMSE/CDR の最終評価日より後である。このため時点ラベルによる単純結合は行わず、
**NPI フォローアップ評価日に最も近い MMSE/CDR** を対応させている
（結果的に全例で「MMSE/CDR の最終利用可能時点」と一致する）。

### 除外基準
- 「資料未提供」「原票なし」→ NPI分類に使えないため除外
- 「判定保留」「未記入」→ 確認事項欄に判定の手がかりがある場合のみ根拠を明記して参考値扱い、
  ない場合は除外（主解析は確定判定のみ、副次解析で参考値を含める）
- NPI のベースラインまたはフォローアップが欠ける症例、MMSE・CDR がともにベースラインのみの症例

### 群分け（3定義をすべて計算）
| 定義 | 群1 | 群2 |
|---|---|---|
| A（主解析） | 改善群＝あり→なし | 非改善群＝それ以外すべて |
| B（代替） | 最終時点なし群＝あり→なし＋なし→なし | 最終時点あり群＝あり→あり＋なし→あり |
| C（参考） | 新規出現群＝なし→あり | それ以外 |

薬剤別解析に加え、追跡期間が異なる点を明記したうえでプール解析も出力する。

### 統計
Mann-Whitney U 検定（両側・正確法）。片群が極端に小さく有意水準5%に原理的に到達しない場合は、
到達可能な最小p値を自動的に注記する。

## 結果の要約

- ΔMMSE・ΔCDR-SB を算出できたのは **レカネマブ14例のみ**（追跡期間中央値11.9か月［6.2, 17.7］）
- **ドナネマブは0例** — NPI が対で揃う6例はいずれも MMSE・CDR のフォローアップ値が未入力、
  MMSE/CDR の追跡がある2例は NPI が初回のみ。したがってプール解析はレカネマブ単独と一致する
- 第7項目（アパシー）の「あり→なし」は1例、第9項目（易怒性）の「あり→なし」も1例であり、
  定義Aでは検定が成立しない
- 定義B・Cを含め、有意差を認めた比較はない

### 深掘り解析の結論

- **確実な所見（全コホート n=71–74、FDR調整後も有意）**: CDR-SB・Global CDR・CDR6領域すべてが
  有意に悪化。MoCA-Jも有意に低下（n=30）。MMSE下位項目で有意に低下したのは**時間見当識のみ**。
  一方 **MMSE合計は有意に変化していない**（p=0.224）。時間見当識の変化はΔCDR-SBとの相関が
  ρ=−0.576 で、MMSE合計とΔCDR-SBの相関（ρ=−0.510）より強い。
- **NPIとの関連は見つからなかった**: NPI関連で計642件の比較を行い、FDR調整後に有意なものは0件。
  調整前に有意だった数件は、いずれも群間のベースライン値の偏りによる**床・天井効果の
  アーティファクト**であり、変化の余地がある症例に限定して再走査すると0件になる。
- **必要症例数**: 最も有望な候補（アパシー改善群 × 時間見当識）でも、1:1配分で総n=11、
  本コホートの実際の群比では総n=37が必要。

詳細は `output/deep_analysis_report.md` と `docs/解析デザイン判断メモ.md` を参照。
