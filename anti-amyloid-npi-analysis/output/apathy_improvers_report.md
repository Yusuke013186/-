# 治療前アパシーが追跡時に消失した2例の探索的検討

生成日時: 2026-09-18 10:59

向きの定義: **ΔMMSE系・ΔMoCA-Jはプラスが改善**、**ΔCDR系はプラスが悪化**。
変化量は「最終利用可能時点 − ベースライン（0か月）」。

**本解析は探索的であり、確認的推論には用いない。**
改善群は2例であるため、検定結果ではなく個別値と分布内の位置づけを主たる所見とする。


## 要約

治療前にNPIアパシーが「あり」で追跡時に「なし」となったのは **2例（L4, L59）**、いずれもレカネマブ例であった。

### 2例に共通してみられた特徴

- **MMSE合計**: +0, +3点（全治療例74例の中央値 -0.5点）
- **CDR-SB**: +2, +0点（全治療例71例の中央値 +0.5点）
- **MMSE時間見当識**: +1, +2点（全治療例73例の中央値 -1点）。2例は全治療例中それぞれ 6/73位、2/73位であった
- **易怒性**: 2例とも「なし→あり」であり、アパシーの消失と易怒性の新規出現が同時に起きていた

### 検定の結果

- 対照A（NPI非改善群）（2 vs 12）: 調整前 p<0.05 は 1件（MMSE 時間見当識）、FDR調整後は 0件
- 対照B（全治療例）（2 vs 72）: 調整前 p<0.05 は 1件（MMSE 時間見当識）、FDR調整後は 0件
- 対照C（アパシー持続群）（2 vs 2）: 調整前 p<0.05 は 0件、FDR調整後は 0件

### 解釈上の注意

- 改善群が2例であるため、検定結果は確認的な根拠とはならない。
- **2例はいずれもMMSE時間見当識のベースラインが2/5点と低く、改善する余地が大きかった。** 一方で全治療例の多くは4〜5点で天井に近く、改善しようがない。時間見当識の差はこの偏りで説明されうるため、所見として提示する際は必ず併記する必要がある。
- 追跡期間が症例間で異なる（6〜24か月）ことも交絡となる。
- CDRの記入の持ち越しが疑われる症例が全体の約4分の1にあり、CDRの「変化なし」の解釈には注意を要する。
