# 治療開始前のNPIアパシーの有無と、その後の認知機能変化との関連

生成日時: 2026-09-18 09:53

向きの定義: **ΔMMSE系・ΔMoCA-Jはプラスが改善**、**ΔCDR系はプラスが悪化**。
変化量は「最終利用可能時点 − ベースライン（0か月）」。


## 要約（結論）

**治療開始前のNPIアパシーの有無は、MMSE・CDRの総合点とも、MMSE下位11項目・CDR下位6領域とも、有意な関連を示さなかった。**

- 解析対象は 16例（アパシーあり5例 vs なし10例、判定保留の1例は別途感度解析）。追跡NPIを要件から外したことで、あり群は前解析の3例から5例に増えている。
- 21転帰のうち、変化量そのものの比較で p<0.05 となったのは **CDR-SB のみ**（p=0.028、Spearman ρ=-0.61）。族内 FDR 調整後は **0件**。
- しかもその方向は直感と逆で、**アパシーあり群のほうが CDR-SB の悪化が小さかった**（Δ中央値 0.0 vs 1.0）。

### この CDR-SB の所見は交絡で説明できる

- **追跡期間の偏り**: あり群の追跡期間は中央値 7.3か月、なし群は 12.15か月。あり群は悪化する時間が短かった。
- **CDRの記入の持ち越しの疑い**: あり群の 4/5例（L59, L60, D1, D2）は CDR6領域が全評価時点で完全に同一。なし群では 1/10例のみ。
- **共変量を加えると消失する**:

| モデル | 調整後の群間差 | p |
|---|---|---|
| 調整なし（変化量そのもの） | -0.95 | 0.041 |
| ベースライン値で調整 | -0.795 | 0.071 |
| 追跡期間で調整 | -0.6359 | 0.134 |
| ベースライン値＋追跡期間で調整 | -0.3361 | 0.382 |
| ベースライン値＋追跡期間＋薬剤で調整 | -0.0539 | 0.873 |

群間差は −0.95 からほぼ 0 まで縮小し、p は 0.87 まで上昇する。この所見は薬剤と追跡期間の偏りで説明され、アパシーの効果とは考えにくい。

### その他の転帰

- MMSE合計・Global CDR はいずれも有意差なし（MMSE合計 p=0.953、Global CDR p=0.594）。
- 最小p値の3転帰: MMSE 遅延再生 p=0.165, CDR 記憶 p=0.254, CDR 地域社会の活動 p=0.254
- MMSE遅延再生はあり群でやや低下が大きい傾向があるが（調整なしの平均差検定 p=0.077）、完全調整モデルでも p=0.102 で有意に達しない。
- MoCA-J はアパシーあり群に測定例がなく比較できない。

### 付随して見つかったデータ品質の問題

CDRが2時点以上ある全 74例のうち **20例（27%）** で、6領域すべてが全評価時点で完全に同一の値であった（レカネマブ 11/59例, ドナネマブ 9/15例）。
再評価ではなく前回値の転記が行われた可能性があり、CDRを主要評価項目とする解析全体に影響する。原資料での確認をお勧めする。

> 注: 第3節の p 値は順位に基づく Mann-Whitney U 検定、第5-B節の p 値は平均差の並べ替え検定であり、同じデータでも値は一致しない。外れ値の影響を受けにくいのは前者、共変量調整ができるのは後者である。
